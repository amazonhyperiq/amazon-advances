حزمة ملفات GitHub لنظام سلف أمازون

هذه الحزمة مخصصة لرفع ملفات الموقع إلى جذر مستودع GitHub.
تحتوي على 16 ملفاً في الجذر ومجلد icons الذي يحتوي أيقونتي التطبيق.

طريقة الرفع:
1) فك ضغط الحزمة.
2) افتح مستودع GitHub.
3) اختر Add file ثم Upload files.
4) ارفع الملفات الستة عشر ومجلد icons إلى جذر المستودع، وليس داخل مجلد فرعي.
5) اضغط Commit changes.

تنبيه مهم:
هذه حزمة ملفات GitHub فقط. لا تشغّل أي ملف SQL من الحزم السابقة؛ تحديث قاعدة البيانات منفصل، والملف السابق الذي سبب خطأ SQL غير مضمّن هنا.
لا تعتبر وظائف الجلسات وتغيير كلمات المرور مكتملة على قاعدة البيانات بمجرد رفع ملفات الموقع؛ تحتاج قاعدة البيانات إلى تحديث صحيح منفصل.
