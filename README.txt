تحديث كلمة المرور:
1) في Supabase > SQL Editor شغّل change_password.sql مرة واحدة.
2) ارفع index.html و app.js واستبدلهما في GitHub.
3) Ctrl+F5 للموقع.
4) تغيير كلمة المرور: اختر الاسم > تغيير كلمة المرور > أدخل الحالية والجديدة.
5) الاسترجاع: يجب أن يكون كود الاسترجاع محفوظاً مسبقاً. إنشاء كود جديد يحتاج كلمة المرور الحالية.
6) لا ترسل VAPID_PRIVATE_KEY أو أي مفتاح سري.
