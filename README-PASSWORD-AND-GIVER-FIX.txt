تحديث محدود لنظام سلف موظفي وعمال أمازون

التغييرات في الواجهة:
- إضافة إظهار/إخفاء لكل حقول كلمات المرور.
- حفظ رقم المانح (giver_id) ضمن جلسة المتصفح بدلاً من الاعتماد على الاسم المعروض.
- منع تحميل جميع أعمدة advance_givers إلى المتصفح؛ تُحمّل فقط id/name/is_active.

تغيير كلمة المرور:
1. شغّل FIX-GIVER-SELF-PASSWORD.sql في Supabase SQL Editor.
2. ارفع app.js وindex.html وstyle.css إلى المستودع مع الحفاظ على بقية الملفات.
3. يختار المانح اسمه، يضغط تغيير كلمة المرور، ويدخل القديمة والجديدة.

مشكلة إضافة السلف لجميع المانحين:
الواجهة تستدعي create_advance_for_giver عبر token. التشخيص السابق أظهر أن حيدر لديه حساباً نشطاً وكلمة مرور مهيأة، لكن لا توجد له جلسة صالحة في advance_giver_sessions. لا يصح استبدال دالة تسجيل الدخول دون معرفة تعريفها وأعمدة جدول الجلسات الفعلية.
شغّل DIAGNOSE-GIVER-SESSIONS.sql وأرسل النتائج؛ بعدها يمكن إعداد إصلاح SQL مطابق للمخطط بدلاً من تخمين أسماء الأعمدة أو كسر دخول بقية المانحين.

مهم:
- لا تحذف أي جداول أو سجلات.
- لا ترفع ملفات SQL إلى الواجهة العامة باعتبارها ملفات تشغيل؛ شغّلها في Supabase SQL Editor.
