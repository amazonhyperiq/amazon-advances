# Amazon Advances V2 — التعديل النهائي

## أهم إصلاح
تم إلغاء إنشاء حدث Push يدوي من الواجهة. قاعدة البيانات هي التي تنشئ الحدث عبر Trigger، والواجهة تستدعي Edge Function فقط بعد نجاح العملية. هذا يمنع تكرار حدث السلفة مرتين.

## الإضافات
- واجهة ملونة وبطاقات موحدة.
- الإجازات والغياب بنفس نمط بقية البطاقات.
- العقوبات والخصومات.
- المكافآت.
- عقوبة الغياب مع منع تكرار نفس واقعة الغياب.
- أزرار تقارير مستقلة للسلف والإجازات والعقوبات والمكافآت.
- يعمل التصميم المتجاوب على الكمبيوتر والموبايل.

## قاعدة البيانات
شغّل `penalties-rewards.sql` في Supabase مرة واحدة لتفعيل جداول العقوبات والمكافآت وقاعدة منع تكرار عقوبة الغياب.

## Push
لا تغيّر VAPID ولا المفتاح الخاص. الإصلاح في `app.js` يعتمد على Trigger الموجود في إعداد Push.
